# THE NOODLES

「stir fly eighteen」をオマージュしたボードゲームです。

- 印刷用カード画像と [`ルール.png`](ルール.png) / [`ラーメン効果表.png`](ラーメン効果表.png)
- 得点ヘルパー: [`noodles.py`](noodles.py) / [`noodles_gui.py`](noodles_gui.py)
- **ブラウザでネット対戦**: [`web/`](web/)（ホスト制 P2P・DB なし）

## ネット対戦を起動

```bash
cd web
npm install
npm run dev
```

詳細は [`web/README.md`](web/README.md) を参照してください。
