# THE NOODLES — ネット対戦

ホスト制の peer-to-peer（PeerJS / WebRTC）で遊ぶブラウザ版です。ゲーム用データベースは使いません。

## 遊び方

1. `npm install && npm run dev`
2. ブラウザで部屋を作成し、表示された部屋コードを友達に共有
3. 友達はコードを入力して参加 → 準備完了 → ホストが開始
4. 印刷版と同じく、捨て宣言・味見・調理・50点先取

## スクリプト

- `npm run dev` — 開発サーバー
- `npm run build` — 静的ファイルを `dist/` に出力（GitHub Pages 等へそのまま配置可）
- `npm test` — 得点計算とルールエンジンのテスト

## 注意

- ホストが切断すると部屋は終了します
- 接続は PeerJS のシグナリングに依存します（厳しい NAT 環境では失敗することがあります）
- 想定人数は 2〜4 人、友達同士向けです
